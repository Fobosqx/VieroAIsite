VIEROAI MINI APP — прототип ленты

Внутри:
- адаптивная лента карточек в две колонки на телефоне;
- категории, поиск, сохранённые идеи;
- бесконечная прокрутка по мере приближения к концу;
- окно загрузки фото и выбора идеи;
- Telegram WebApp SDK.

ВАЖНО: это пока фронтенд-демо. Загрузка файла и генерация ещё не подключены к Python-боту, лимиты не списываются. Для настоящей генерации надо опубликовать страницу по HTTPS, добавить кнопку web_app в боте, проверить Telegram WebApp initData на сервере и отправлять фото серверному обработчику. Никогда не помещайте API-ключи в HTML/JavaScript.

Для просмотра распакуйте архив и откройте index.html. В Telegram Mini App сайт должен быть доступен по HTTPS.
